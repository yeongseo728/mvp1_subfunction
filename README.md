# 집콕체크 · 실험용 저장소

전월세 계약 전에 확인할 질문을 체크리스트로 모아 주고, 계약 뒤에는 챙길 일정을 달력으로 보여 주는 앱이에요.
이 저장소는 **새 기능을 먼저 시험하는 곳**이에요. 실제 사이트(원래 저장소 mvp1)와는 연결되어 있지 않아요.

## 지금 시험 중인 기능
- **계약 케어** (아래 탭 두 번째): 「이 집으로 계약 완료」 → 계약일·잔금이삿날·만기일로 꼭 챙길 일정 9개를 달력에 채우고, 할 일을 체크하고, 날짜를 눌러 내 일정을 넣어요. 계약을 완료하면 앱을 열 때 계약 케어부터 보여요.

## 처음 한 번 설정
- **시세 자료 자동 받기**: 저장소 → Settings → Secrets and variables → Actions → New repository secret → 이름 `RENT_KEY`, 값은 공공데이터포털 인증키. 없으면 매일 새벽 4시 실행이 실패해요.
- **사이트로 열어 보기**: Vercel에서 이 저장소를 새 프로젝트로 연결해요. AI 기능은 Vercel 설정에 `GEMINI_API_KEY`, 중개사무소 조회는 `BROKER_KEY`가 있어야 돌아가요.

자세한 규칙은 `CLAUDE.md`, 판단 기준은 `판단기준.md`, 기획은 `docs/PRD_v1.2.md`에 있어요.
